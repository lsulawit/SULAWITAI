# SULAWIT AI — Kids Translator Chat

เวอร์ชันนี้ถูกปรับใหม่ให้เป็นแนวสดใสสำหรับเด็กมากขึ้น โดยมีการเปลี่ยนแปลงดังนี้

- โทนสีสว่าง พาสเทล อ่านง่าย
- ฟอนต์น่ารักขึ้น
- เพิ่มตัวการ์ตูน/มาสคอตแบบ CSS animation
- เพิ่มแผงเพื่อนแปลภาษา (LULU)
- ตัดปุ่ม quick prompts เดิม เช่น “สุภาพขึ้น”, “คุยกับเพื่อน”, “จีน + พินอิน” ออก
- รองรับมือถือและ iPad
- ใช้โหมดแปลฟรีได้ทันทีผ่าน `/api/translate`

## Deploy

อัปขึ้น GitHub และเชื่อมกับ Vercel ได้เหมือนเดิม

## โหมดฟรี

ไฟล์ `api/translate.js` ใช้งานตัวแปลฟรีได้ทันทีโดยไม่ต้องใส่ API Key
